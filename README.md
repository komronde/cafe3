# MAISON — Coffee & Kitchen

Premium cafe website starter built with **React + TypeScript + Vite**.

## Ishga tushirish

1. Kompyuterda Node.js LTS o‘rnatilgan bo‘lsin: https://nodejs.org
2. Ushbu papkani VS Code orqali oching.
3. VS Code terminalida quyidagilarni bajaring:

```bash
npm install
npm run dev
```

4. Terminalda ko‘rsatilgan manzilni brauzerda oching (odatda `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Nimalar bor?

- Responsive premium cafe landing page
- Bosh sahifa, biz haqimizda, menyu va aloqa bo‘limlari
- Menyu kategoriyalari bo‘yicha filter
- Stol band qilish modal oynasi (hozircha frontend demo)
- Kirish oynasi (hozircha frontend demo)
- Mobil navigatsiya
- TypeScript komponentlari

## Muhim

Bu versiyada **database va backend yo‘q**. Band qilish formasi hozircha ma'lumotni serverga yubormaydi; faqat demo tasdiq xabarini ko‘rsatadi. Haqiqiy bron, login/ro‘yxatdan o‘tish va admin panel uchun keyin backend hamda database ulash kerak bo‘ladi.

Rasmlar Unsplash manbalaridan internet orqali yuklanadi. Manzil, telefon va Instagram nomi demo ma'lumotlar — o‘zingiznikiga almashtiring.
